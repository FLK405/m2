# 用户管理系统

## 1. 系统概述

用户管理系统用于实现数据访问控制和权限管理，确保数据安全性和访问权限的精确控制。系统采用三级权限管理机制。

## 2. 权限等级

系统将用户分为三个等级：

1. 超级管理员（role_level = 0）

    - 具有系统所有权限
    - 可以添加、移除管理员
    - 可以管理所有用户
    - 可以访问和修改所有资源

2. 管理员（role_level = 1）

    - 可以管理所有资源
    - 可以管理普通用户
    - 可以查看所有文档
    - 可以修改所有文档

3. 普通用户（role_level = 2）
    - 只能查看文档
    - 只能更新属于自己的文档
    - 无法管理其他用户

## 3. 数据库设计

### 3.1 用户表(users)

| 字段名     | 类型         | 说明                | 是否必填 |
| ---------- | ------------ | ------------------- | -------- |
| id         | SERIAL       | 主键                | 是       |
| username   | VARCHAR(50)  | 用户名              | 是       |
| password   | VARCHAR(255) | 加密密码            | 是       |
| nickname   | VARCHAR(50)  | 昵称                | 否       |
| email      | VARCHAR(100) | 邮箱                | 否       |
| phone      | VARCHAR(20)  | 电话                | 否       |
| role_level | INTEGER      | 权限等级(1-3)       | 是       |
| status     | SMALLINT     | 状态(1:启用,0:禁用) | 是       |
| created_at | TIMESTAMP    | 创建时间            | 是       |
| updated_at | TIMESTAMP    | 更新时间            | 是       |

## 4. 服务端接口列表

### 4.1 用户管理接口

#### 4.1.1 用户列表

-   请求路径：`/api/user/list`
-   请求方法：GET
-   请求参数：
    -   page: 页码（默认 1）
    -   pageSize: 每页数量（默认 10）
    -   keyword: 搜索关键词（可选）
-   响应数据：

```json
{
    "code": 200,
    "data": {
        "total": 100,
        "list": [
            {
                "id": 1,
                "username": "admin",
                "real_name": "管理员",
                "email": "admin@example.com",
                "phone": "13800138000",
                "role_level": 3,
                "status": 1,
                "created_at": "2024-03-20 10:00:00"
            }
        ]
    }
}
```

#### 4.1.2 创建用户

-   请求路径：`/api/user/register`
-   请求方法：POST
-   请求参数：

```json
{
    "username": "string",
    "password": "string",
    "nickname": "string",
    "email": "string",
    "phone": "string",
    "role_level": 1
}
```

-   响应数据：

```json
{
    "code": 0,
    "message": "创建成功"
}
```

#### 4.1.3 更新用户

-   请求路径：`/api/user/update`
-   请求方法：PUT
-   请求参数：同创建用户
-   响应数据：

```json
{
    "code": 0,
    "message": "更新成功"
}
```

#### 4.1.4 删除用户

-   请求路径：`/api/user/delete`
-   请求方法：DELETE
-   响应数据：

```json
{
    "code": 0,
    "message": "删除成功"
}
```

### 4.2 通用响应格式

所有接口响应都遵循以下格式：

```json
{
    "code": 0,
    "message": "string", // 提示信息
    "data": {} // 响应数据，可选
}
```
