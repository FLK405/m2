# UHMWPE纤维及其复合材料性能数据库 - 用户手册

## 1. 引言

### 1.1 系统目的
本数据库系统旨在收集、管理和分析超高分子量聚乙烯（UHMWPE）纤维及其复合材料的各种性能数据。系统支持从前端树脂与纺丝工艺、纤维基本性能、微观结构特征，到树脂及界面性能、复合材料结构与性能，直至终端产品防弹性能的全链条数据管理。此外，系统还包含文献与标准管理及用户权限管理功能。

### 1.2 系统模块概述
系统主要包含以下核心模块：
-   **用户管理**: 负责用户注册、登录、权限分配。
-   **前端树脂与纺丝工艺**: 管理用于制备特定纤维批次的前端树脂特性和主要纺丝工艺参数。
-   **纤维性能**: 管理纤维的基本信息、分子量、拉伸性能、蠕变性能、动态拉伸性能及热性能（DSC, TGA, 热导率）。
-   **微观结构特征**: 管理纤维的相结构 (NMR/Raman)、取向与晶体结构 (WAXD/SAXS/Sonic)、SEM图像及XPS分析数据。
-   **树脂及界面性能**: (占位) 管理树脂的力学性能及纤维/树脂界面性能。
-   **复合材料结构与性能**: (占位) 管理复合材料的基本信息及其各项性能数据。
-   **终端产品防弹性能**: (占位) 管理终端产品（如防弹衣、头盔）的信息及其防弹测试结果。
-   **文献与标准**: (占位) 管理相关的学术文献、行业标准和测试方法。
-   **系统工具**: (占位) 提供系统帮助文档等。

## 2. 快速入门

### 2.1 系统访问
通过指定的URL在浏览器中访问本系统。您需要现代浏览器（如Chrome, Firefox, Edge）以获得最佳体验。

### 2.2 系统布局
系统界面主要分为：
-   **顶部导航栏**: 显示系统名称和主要功能入口。
-   **左侧导航菜单**: 列出所有可访问的数据管理模块。
-   **主内容区**: 显示当前选定模块的数据列表、表单或详情。

### 2.3 用户注册
新用户需要注册账户才能访问系统。
1.  点击界面右上角的“注册”按钮。
2.  在注册表单中填写用户名、密码（及确认密码）、昵称（可选）、邮箱（可选）、电话（可选）。
3.  选择用户角色等级（根据实际权限分配）。
4.  点击“注册”完成。

*(注: 用户注册功能描述基于 `docs/用户管理.MD` 中的通用字段，实际角色分配可能由管理员操作。)*

### 2.4 用户登录
已注册用户通过以下步骤登录：
1.  点击界面右上角的“登录”按钮。
2.  输入用户名和密码。
3.  点击“登录”。

### 2.5 系统导航
登录后，通过左侧导航菜单选择需要访问的数据模块。点击菜单项会在主内容区加载相应模块的界面。

## 3. 模块：前端树脂与纺丝工艺

### 3.1 访问模块
点击左侧导航菜单中的“前端树脂与纺丝工艺”链接。

### 3.2 查看数据
进入模块后，您将看到前端树脂与纺丝工艺记录的列表。列表通常包含以下关键信息：
-   目标纤维批号
-   使用树脂牌号
-   原液浓度 (%)
-   纺丝温度 (°C)
-   总拉伸倍数
-   操作员
列表上方通常有搜索框，可以按关键词（如纤维批号、树脂牌号）进行筛选。分页控件用于浏览大量数据。

### 3.3 添加新记录
1.  点击“添加新记录”按钮，将弹出数据录入表单。
2.  表单字段包括：
    *   目标纤维批号 (必填)
    *   树脂ID (关联到树脂库，必填)
    *   树脂牌号
    *   树脂分子量 (数均, 重均, PDI)
    *   树脂结晶度 (%) 与熔点 (°C)
    *   原液浓度 (%)
    *   纺丝温度 (°C)
    *   双螺杆速率 (rpm)
    *   凝固浴组成与温度 (°C)
    *   拉伸温度 (°C) 与总拉伸倍数
    *   溶剂去除工艺与后处理工艺
    *   操作员与备注
3.  填写完毕后，点击“创建”按钮保存。

### 3.4 编辑记录
1.  在数据列表中找到需要修改的记录。
2.  点击该记录对应的“编辑”按钮。
3.  表单将加载现有数据，修改后点击“更新”按钮保存。
*(注: 编辑功能基于通用Web应用实践，具体实现可能依赖后端接口)*

### 3.5 删除记录
1.  在数据列表中找到需要删除的记录。
2.  点击该记录对应的“删除”按钮。
3.  系统可能会提示确认删除。确认后，记录将被移除。
*(注: 删除功能基于通用Web应用实践，具体实现可能依赖后端接口)*

## 4. 模块：纤维性能

### 4.1 访问模块
点击左侧导航菜单中的“纤维性能”链接（路径 `/fiber-properties`）。

### 4.2 查看纤维基本信息
进入模块后，主界面将显示纤维基本信息列表。关键信息包括：
-   ID (系统生成)
-   制造商
-   牌号
-   批号
-   纤度 (dtex)
列表上方有搜索框和“添加新记录”按钮。

### 4.3 添加纤维基本信息
1.  点击“添加新记录”按钮，打开“添加新纤维记录”表单。
2.  表单字段包括：
    *   牌号 (必填)
    *   批号 (必填)
    *   制造商
    *   纺丝工艺ID (关联)
    *   纤度 (dtex)
    *   单丝直径 (μm)
    *   纤维根数
    *   样品来源
    *   生产日期
    *   样品图片路径
    *   备注
3.  填写完毕后，点击“创建”按钮。

### 4.4 编辑与删除纤维基本信息
-   **编辑**: 点击列表中记录的“编辑”按钮，在表单中修改后保存。 (目前为占位符，前端已连接mock后端)
-   **删除**: 点击列表中记录的“删除”按钮，确认后删除。 (目前为占位符)

### 4.5 查看与管理详细性能数据
-   点击列表中记录的“详情”按钮（或通过特定导航），可进入该纤维的详细性能数据管理页面。
-   此页面将分块显示与该纤维关联的各类性能测试数据：
    *   分子量属性
    *   拉伸性能
    *   蠕变性能
    *   动态拉伸性能
    *   热性能 - DSC
    *   热性能 - TGA
    *   热导率
-   每个性能数据块通常有其独立的“添加”、“编辑”、“删除”操作。
*(注: 详细性能数据的添加/编辑/删除表单和具体交互流程将在后续开发中完善。目前主列表已连接mock后端可显示纤维基本信息。)*

## 5. 模块：微观结构特征

### 5.1 访问模块
点击左侧导航菜单中的“微观结构”链接（路径 `/microstructure`）。

### 5.2 模块概述
此模块用于管理纤维的各项微观结构表征数据。主界面将按以下类别分块显示数据：
-   相结构 (NMR/Raman)
-   取向与结晶度 (WAXD/Sonic)
-   SEM图像
-   XPS分析

用户需要先选择或指定一个**纤维ID**（未来可能通过主纤维列表选择跳转），然后才能查看或添加与该纤维相关的微观结构数据。

### 5.3 添加数据
在每个微观结构特征子 بخش (section) 内：
1.  点击相应的“添加[类型]数据”按钮 (例如，“添加相结构数据”)。
2.  将弹出一个针对该数据类型的表单。
3.  **重要**: 表单内需要确保已选择了正确的**纤维ID**。

#### 5.3.1 添加相结构数据 (NMR/Raman)
-   表单字段包括：测试方法 (NMR/Raman), 测试日期, 测试机构/设备, NMR特定参数 (无定形区占比等), Raman特定参数 (结晶度, 特征峰), 图表/原始数据路径, 备注。
-   根据选择的测试方法 (NMR/Raman)，表单会显示相应的特定字段。

#### 5.3.2 添加取向与结晶度数据 (WAXD/Sonic)
-   表单字段包括：测试方法 (WAXD/SAXS/SonicModulus), 测试日期, 测试机构/设备, WAXD/SAXS特定参数 (晶粒尺寸, 取向因子, d-spacing), 声速法特定参数 (声速, 取向因子, 模量), 图表/原始数据路径, 备注。
-   根据选择的测试方法，表单会显示相应的特定字段。

#### 5.3.3 添加SEM图像数据
-   表单字段包括：图像路径 (必填), 试样名称, 测试日期, 测试机构/设备, 放大倍数, 加速电压, 形貌特征描述, 分析结果 (如EDS), 备注。

#### 5.3.4 添加XPS分析数据
-   表单字段包括：测试日期, 测试机构/设备, 各元素原子百分比 (C, O, N), 其他元素含量, 化学态信息, XPS谱图路径, 原始数据路径, 备注。

### 5.4 查看、编辑与删除数据
-   每个子 بخش (section) 将以表格形式列出已有的测试记录。
-   每条记录旁将有“编辑”和“删除”按钮。
*(注: 目前，仅“添加相结构数据”的表单 (`mc-phase-structure-form`) 已创建并连接到mock后端。其他类型的表单 (`mc-orientation-crystallinity-form`, `mc-sem-form`, `mc-xps-form`) 也已创建，但其对应列表和后端mock连接尚未完全实现。数据列表显示和编辑/删除功能均为占位符。)*
