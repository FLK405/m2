# 前端树脂与纺丝工艺

## 字段列表

-   fiber_batch_no: 目标纤维批号 (用于关联到最终纤维)
-   resin_id: 使用的树脂 ID (关联到 Resins 表)
-   resin_grade: 使用的树脂牌号 (可冗余或从 resin_id 获取)
-   resin_mn: 所用树脂数均分子量 (g/mol)
-   resin_mw: 所用树脂重均分子量 (g/mol)
-   resin_pdi: 所用树脂多分散系数 (Mw/Mn)
-   resin_crystallinity: 所用树脂结晶度 (%)
-   resin_melting_point: 所用树脂熔点 (°C)
-   solution_concentration: 原液浓度 (%)
-   spinning_temp: 纺丝温度 (°C)
-   screw_speed: 双螺杆速率 (rpm)
-   bath_composition: 凝固浴组成
-   bath_temp: 凝固浴温度 (°C)
-   drawing_temp: 拉伸温度 (°C)
-   drawing_ratio: 总拉伸倍数
-   solvent_removal: 溶剂去除工艺
-   post_process: 后处理工艺 (如表面改性)

## 技术栈

### 后端

-   框架：Node.js + Express
-   数据库：PostgreSQL
-   ORM：Prisma
-   接口文档：Swagger/OpenAPI

### 前端

-   框架：Web Components
-   UI 组件：Lit Element
-   状态管理：Redux
-   请求库：Fetch API
-   构建工具：Vite

## 数据库设计

```sql
CREATE TABLE spinning_process (
    id SERIAL PRIMARY KEY,
    fiber_batch_no VARCHAR(50) UNIQUE NOT NULL,
    resin_id VARCHAR(50) NOT NULL,
    resin_grade VARCHAR(100),
    resin_mn DECIMAL(10,2),
    resin_mw DECIMAL(10,2),
    resin_pdi DECIMAL(5,2),
    resin_crystallinity DECIMAL(5,2),
    resin_melting_point DECIMAL(5,2),
    solution_concentration DECIMAL(5,2),
    spinning_temp DECIMAL(5,2),
    screw_speed DECIMAL(10,2),
    bath_composition TEXT,
    bath_temp DECIMAL(5,2),
    drawing_temp DECIMAL(5,2),
    drawing_ratio DECIMAL(5,2),
    solvent_removal TEXT,
    post_process TEXT,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_fiber_batch_no ON spinning_process(fiber_batch_no);
CREATE INDEX idx_resin_id ON spinning_process(resin_id);
```

## API 设计

### 接口定义

```typescript
interface SpinningProcess {
    fiber_batch_no: string;
    resin_id: string;
    resin_grade?: string;
    resin_mn?: number;
    resin_mw?: number;
    resin_pdi?: number;
    resin_crystallinity?: number;
    resin_melting_point?: number;
    solution_concentration?: number;
    spinning_temp?: number;
    screw_speed?: number;
    bath_composition?: string;
    bath_temp?: number;
    drawing_temp?: number;
    drawing_ratio?: number;
    solvent_removal?: string;
    post_process?: string;
}
```

### 接口端点

```
POST   /api/spinningProcess.create     // 创建新记录
POST   /api/spinningProcess.list       // 获取记录列表（支持分页和筛选）
POST   /api/spinningProcess.get        // 获取单条记录
POST   /api/spinningProcess.update     // 更新记录
POST   /api/spinningProcess.delete     // 删除记录
```

## API 接口文档

### 1. 获取纺丝工艺列表

```typescript
POST /api/spinningProcess.list

请求参数：
{
    page: number (页码，默认1)
    pageSize: number (每页数量，默认10)
    search?: string (搜索关键词，可选)
    startDate?: string (开始日期，可选)
    endDate?: string (结束日期，可选)
}

响应数据：
{
    total: number,
    items: SpinningProcess[],
    page: number,
    pageSize: number
}
```

### 2. 获取单个纺丝工艺记录

```typescript
POST /api/spinningProcess.get

请求参数：
{
    fiber_batch_no: string
}

响应数据：
SpinningProcess
```

### 3. 创建纺丝工艺记录

```typescript
POST /api/spinningProcess.create

请求数据：
SpinningProcess

响应数据：
{
    success: boolean,
    data: SpinningProcess
}
```

### 4. 更新纺丝工艺记录

```typescript
POST /api/spinningProcess.update

请求数据：
{
    fiber_batch_no: string,
    data: Partial<SpinningProcess>
}

响应数据：
{
    success: boolean,
    data: SpinningProcess
}
```

### 5. 删除纺丝工艺记录

```typescript
POST /api/spinningProcess.delete

请求参数：
{
    fiber_batch_no: string
}

响应数据：
{
    success: boolean
}
```

### 错误响应格式

```typescript
{
    error: {
        code: string,
        message: string
    }
}
```
